# Ishaan Biradar — Portfolio (GitHub Pages)

Responsive static portfolio built with plain HTML, CSS and JavaScript. No build step or paid service is required.

## Publish on GitHub Pages
1. On GitHub, create a **public** repository named `ishaanbiradar.github.io` (for username `ishaanbiradar`).
2. Upload `index.html`, `styles.css`, and `script.js` to the repository root. Upload these files individually; do not leave them only inside the ZIP.
3. Open repository **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, branch `main`, folder `/(root)`, then Save.
5. Wait for the Pages deployment to complete. GitHub shows the live URL in Settings → Pages.
